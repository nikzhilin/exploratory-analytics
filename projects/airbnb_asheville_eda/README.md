# Airbnb Asheville EDA

Данный проект посвящён исследованию рынка Airbnb в городе Ашвилл (Asheville, North Carolina, United States) на основе квартального снимка объявлений на момент 22 сентября 2025 года.

Цель проекта - последовательно зафиксировать состав исходного набора данных, выполнить техническую очистку, сформировать производные признаки и перейти к интерпретации структуры рынка через цену, доступность, географию и масштаб хостов.

## Состав проекта

Проект организован как линейная аналитическая цепочка. Каждый ноутбук закрывает отдельный этап подготовки или интерпретации данных, а результат предыдущего этапа используется на следующем.

### Ноутбуки
1. `01_overview.ipynb` - общий обзор набора данных, его структуры и первичных ограничений.
2. `02_technical_cleaning.ipynb` - проверка дублей, пропусков, типов данных и логических несоответствий.
3. `03_descriptive_layers.ipynb` - описательные статистики, распределения, выбросы и базовые зависимости между признаками.
4. `04_feature_engineering.ipynb` - построение производных признаков для более устойчивого анализа цены, доступности и активности отзывов.
5. `05_derived_feature_analysis.ipynb` - проверка распределений и аналитической полезности производных признаков.
6. `06_market_structure_and_geo.ipynb` - анализ рыночной структуры и географической неоднородности.
7. `07_host_and_demand.ipynb` - сопоставление масштаба хостов с ценой, условиями размещения и признаками текущего спроса.
8. `08_summary.ipynb` - итоговая интерпретация результатов и общие выводы по рынку.

### Данные
- `data/raw/listings.csv` - исходный набор данных.
- `data/processed/listings_clean.parquet` - очищенная версия набора данных после технической подготовки.
- `data/processed/listings_analytics.parquet` - аналитическая таблица с производными признаками.
